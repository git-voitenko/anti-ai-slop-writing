## Заборонені фрази

- «У сучасному світі...» / «У наш час...» / «В епоху цифрових технологій...»
- «Не секрет, що...» / «Як відомо...»
- «Варто зазначити, що...» / «Важливо зазначити / розуміти...» / «Слід зазначити...» / «Не можна не відзначити...» – заборонений філер-зачин; НЕ плутати з «варто + дієслово дії» як рекомендацією читачеві («варто відповісти до кінця листопада») – це легальна і бажана форма м'якого заклику
- «Давайте розберемося...» / «Розгляньмо детальніше...» / «Зануримося у світ...»
- «Що ж таке X?» (риторичний зачин)
- «Отже, ...» / «Підбиваючи підсумки...» / «У підсумку...» / «На завершення...» / «Таким чином, ...» (як фінал)
- «Загалом, ...» (зачин абзацу)
- «Відіграє важливу / ключову роль» / «Не є винятком» / «Посідає особливе місце»
- «Багатий досвід» / «Індивідуальний підхід»
- «Це не просто X — це Y»
- «Від X до Y» (зачин-діапазон) / «Хай ви X чи Y...» / «Незалежно від того, чи...»
- «По-перше... По-друге... По-третє...» (механічна нумерація)
- «Ось деякі з них» / «Особливо корисно» (рекламні зв'язки)
- «Як-от», «таких як» – ланцюжками в кожному абзаці
- «Сподіваюся, це допоможе» / «Якщо виникнуть запитання, не соромтеся звертатися» / «Гарного дня!» (автопідпис)
- «Спойлер: ...» / «Готові дізнатися більше?»

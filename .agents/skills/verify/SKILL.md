# verify

1. Из корня репозитория (или своего дерева) — `bash tools/verify.sh --fast`, вывод показать. Вход один на репозиторий;
   первым шагом он вызывает `tools/kit-check.sh` (сверка managed-файлов `agent-kit` с `.agent-kit.lock`).
2. Код 0 — можно коммитить. Код 77 (SKIP: не хватает среды) или любой другой ненулевой — не коммитить:
   назвать причину и чинить (SKIP — сказать владельцу, чего не хватает).
3. Красный `kit-check` — managed-файл или ядро `AGENTS.md` правились мимо `kit-sync`: вернуть файл
   (`git checkout origin/main -- <путь>`), саму правку нести PR в `agent-kit`.
4. Полный прогон (без `--fast`) — когда этого требует раздел `## Проверки` проектного блока `AGENTS.md`.

Контракт входа `verify.sh` и цикл целиком — `AGENTS.md`, «Как работаем».
